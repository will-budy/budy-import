# Company presentations

Where teams build and share Budy's company presentations. Private repository.

| Folder | What it is |
| --- | --- |
| [`v1/`](v1/) | The first version: slide decks as a small web site, with a live demo of the Budy phone app. Runs fully on one laptop. Served under `/v1/`. |

Everything lives in a version folder. New work goes into `v1/` until a later version exists.

- **Using or running a deck:** see [`v1/README.md`](v1/README.md).
- **Changing a deck, or working with an AI agent:** start with [`AGENTS.md`](AGENTS.md).
- **Access:** the GTM team can push branches and open pull requests. Engineering can read. `main` only changes through a reviewed pull request.
