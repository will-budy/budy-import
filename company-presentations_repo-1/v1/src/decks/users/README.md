# Personal decks

Each person can have a folder here for their own decks and drafts: `src/decks/users/<your-name>/<deck-name>/`.
A deck folder holds a `deck.json` and the slide pictures. It shows up at `/v1/users/<your-name>/<deck-name>` and on the home page, with no code change.
See `AGENTS.md` in the `v1` folder, section "Adding decks", for the steps.
