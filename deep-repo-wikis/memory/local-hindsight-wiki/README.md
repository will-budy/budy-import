# Hindsight Developer Reference Wiki

Hindsight is an agent memory system that gives AI agents biomimetic long-term memory (world facts, experience facts, and consolidated mental models) through a retain/recall/reflect API. This wiki covers the core Python engine, its API surfaces, client tooling, and the extensive integrations library, all designed to be portable across LLM, storage, and deployment providers (BYOC/BYOK).
