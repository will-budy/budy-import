# Services Affected

This folder tracks the services expected to be created or significantly upgraded for Mark 2.

Each service folder should contain:

- `hld.md` for service-level architecture and workflow design
- `trd.md` for implementation details, tech choices, test strategy, and deployment notes
- `nexus-contracts.md` when other services call this service through Temporal Nexus or shared activities

The list is provisional until the Mark 2 PRD is finalized.
